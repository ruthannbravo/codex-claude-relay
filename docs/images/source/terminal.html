The Relay · what you actually see

Quiet terminal, full receipts

One line per step. Everything the assistants did is saved to a log, and each review is committed.

$ relay.py run --task "Check CC03/CC05 consistency" --check 2 --calls 12
Round 1: Claude working… done
Round 1: Codex checking… approve
Relay stopped: approved by codex in round 1; 12 of 12 live calls used

A real run (task text shortened): Claude ran six tests within a 12-call budget; Codex re-scored all six itself before approving.
